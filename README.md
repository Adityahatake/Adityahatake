## 🗺️ Featured Projects

### 📚 Nexora — RAG Book Assistant
`Python` `FastAPI` `LangChain` `ChromaDB` `Groq` `React` `TypeScript` • *Feb 2026 – Oct 2026*

A full-stack Retrieval-Augmented Generation application for conversational querying of PDF books, tested on **30+ books**. Nexora combines semantic search with context-grounded LLM answers and page-level source citations.

- Built a document-ingestion pipeline using PyPDFLoader, OpenAI embeddings, and ChromaDB.
- Added configurable chunking and Maximal Marginal Relevance (MMR) retrieval to find diverse, relevant context.
- Integrated Groq for LLM inference and served the application through FastAPI with a React and TypeScript frontend.
- Developed an assessment engine for MCQs and fill-in-the-blank questions, including semantic answer validation, difficulty levels, mastery scoring, and feedback.

📌 [View on GitHub](https://github.com/Adityahatake/Nexora-Ai)
